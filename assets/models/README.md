# Shelf model

The projects page shelf (`js/shelf-3d.js`) auto-loads `shelf.glb` from this
folder if present. Until then it falls back to a procedural shelf built in
Three.js.

To use the Mint-generated "Deep Space Display Shelf" model instead:

1. Open the Mint chat: https://mint.gg/chat/ph74xa8nrkc0wcdmdtsb6t9c5d8bedy4
2. Export/download the GLB from there (API downloads were disabled for this
   asset at generation time, so it has to come from the Mint UI directly).
3. Save it here as `shelf.glb`.
4. Reload projects.html — no code changes needed.
